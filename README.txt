Koshkool — نسخة مرتبطة بـ Supabase (حسابات أونلاين)

ماذا تفعل هذه النسخة؟
- إنشاء حساب بالبريد الإلكتروني وكلمة مرور عبر Supabase Auth.
- تسجيل الدخول من أجهزة ومتصفحات مختلفة بنفس الحساب.
- تأكيد البريد الإلكتروني عند تفعيل خيار التأكيد في Supabase.
- استعادة كلمة المرور عبر رابط البريد.
- إنشاء ملف شخصي لكل طالب تلقائياً في جدول profiles.
- دور افتراضي student، ولا يمكن للطالب تغيير دوره من الموقع.
- صفحة لوحة التحكم تعرض اسم الحساب ونوعه.

الخطوة 1 — إعداد قاعدة البيانات:
1) افتح مشروعك في Supabase.
2) من القائمة افتح SQL Editor.
3) اضغط New query.
4) افتح الملف supabase/setup.sql وانسخ كل محتواه إلى SQL Editor.
5) اضغط Run وانتظر نجاح التنفيذ.

الخطوة 2 — وضع بيانات الربط:
1) افتح الملف js/supabase-config.js.
2) استبدل PASTE_YOUR_PROJECT_URL_HERE بعنوان Project URL.
3) استبدل PASTE_YOUR_PUBLISHABLE_KEY_HERE بقيمة Publishable key.
4) لا تضع Secret key أو service_role أو كلمة مرور قاعدة البيانات في ملفات الموقع.

الخطوة 3 — إعداد رابط الموقع:
1) شغّل الموقع من خلال Live Server أو ارفعه إلى استضافة HTTPS.
2) في Supabase افتح Authentication > URL Configuration.
3) ضع رابط الموقع في Site URL.
4) أضف روابط صفحات الموقع إلى Redirect URLs، ومنها:
   http://127.0.0.1:5500/**
   http://localhost:5500/**
   واستبدل المنفذ إذا كان Live Server يستخدم منفذاً مختلفاً.
5) إعداد البريد: Authentication > Providers > Email.
   في التجربة يمكن تعطيل Confirm email لتسجيل الدخول مباشرة، لكن عند النشر الفعلي يُفضّل تفعيل التأكيد وضبط SMTP موثوق.

الخطوة 4 — إنشاء حساب الأدمن:
1) افتح صفحة إنشاء الحساب في الموقع.
2) سجّل حساباً ببريد إلكتروني حقيقي تملكه أنت وكلمة مرور جديدة قوية (10 أحرف على الأقل).
3) أكّد البريد إذا كان التأكيد مفعّلاً.
4) افتح Supabase > SQL Editor.
5) افتح الملف supabase/make-admin.sql.
6) استبدل admin-email@example.com ببريد حسابك الحقيقي.
7) نفّذ الاستعلام. سيصبح اسم المستخدم admin0100725 ودوره admin.
ملاحظة: admin0100725 هو اسم المستخدم داخل الملف الشخصي، أما تسجيل الدخول في هذه النسخة فيكون بالبريد الإلكتروني وكلمة المرور. لا تستخدم كلمة المرور التي كتبتها سابقاً في المحادثة؛ اختر كلمة جديدة لا تشاركها.

مهم:
- لا يمكن جعل الحساب يعمل على كل الأجهزة قبل رفع الموقع على استضافة عامة HTTPS وربط Supabase.
- تسجيل الدخول هنا بالبريد الإلكتروني. تسجيل الدخول برقم الهاتف يحتاج تفعيل مزود SMS وإعداداته وقد تكون له تكلفة.
- المفتاح Publishable/anon مصمم للاستخدام في المتصفح مع سياسات RLS. لا تنشر أبداً Secret/service_role.
- إعداد RLS في setup.sql يمنع الطالب من قراءة ملفات الآخرين أو ترقية نفسه.
- لا توجد لوحة إدارة متكاملة بعد؛ هذه النسخة تميّز حساب الأدمن وتعرض دوره فقط. أي إجراءات إدارية حساسة يجب تنفيذها عبر سياسات وخادم موثوق.
- لا تخزن كلمات المرور في TXT أو RS.
